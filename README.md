# FabClothing Cloud Migration Project

## Overview

A simulated technology consulting project analysing the migration
of an on-premise retail environment to AWS.

## Business Challenge

FabClothing operates an on-premise infrastructure environment
with challenges around scalability, infrastructure maintenance,
resource utilisation and disaster recovery.

## Proposed AWS Architecture

The proposed architecture uses:

- Amazon EC2
- Amazon RDS
- Amazon S3
- Application Load Balancer
- Amazon CloudWatch
- AWS networking and security services

## Proof of Concept

A web server was deployed using Amazon EC2 and Apache.

The POC successfully hosted a functional FabClothing webpage
on an Amazon EC2 instance.

## Financial Analysis

The project includes an estimated comparison between the
existing on-premise environment and the proposed AWS environment.

AWS costs are based on defined workload assumptions and
usage-based AWS pricing.

## Migration Strategy

The proposed migration follows:

Assess → Design → Build → Pilot → Migrate → Optimise

## Key Risks

- Data loss
- Application downtime
- Security misconfiguration
- Unexpected cloud costs
- Migration delays
